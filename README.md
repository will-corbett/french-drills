# Imparfait ou passé composé ?

A small static web app for drilling when French uses the imparfait and when it uses the passé composé.
Each sentence has its past-tense verbs blanked out; you either choose between the two tenses or type the
form yourself. Missed sentences come back until you get them right twice. Progress is stored in your
browser only.

## Running locally

```bash
python3 -m http.server 8765
```

Then open http://localhost:8765. There is no build step for the site itself.

## Rebuilding the sentence data

`data/sentences.json` is generated by `scripts/build_data.py` (Python 3, standard library only). Download
and unpack these into one folder, then run `python3 scripts/build_data.py THAT_FOLDER`:

- https://downloads.tatoeba.org/exports/per_language/fra/fra_sentences_detailed.tsv.bz2
- https://downloads.tatoeba.org/exports/per_language/fra/fra-eng_links.tsv.bz2
- https://downloads.tatoeba.org/exports/per_language/eng/eng_sentences.tsv.bz2
- https://downloads.tatoeba.org/exports/user_languages.tar.bz2
- http://www.lexique.org/databases/Lexique383/Lexique383.tsv

The script keeps only sentences written by self-declared native French speakers that have an English
translation, finds verbs in either tense, and generates the same verb in the other tense as the wrong
option. It skips anything it cannot convert cleanly (direct-object pronouns, inversion, `si` clauses,
plus-que-parfait, and so on).
